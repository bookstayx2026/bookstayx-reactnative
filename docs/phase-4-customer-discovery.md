# Phase 4 — Customer discovery

Phase 4 ports the approved BookStayX customer discovery surfaces to Expo/React Native while keeping authentication and backend integration out of scope.

## Delivered

- Source-matched home hero, stats, destination grid, property tabs, and horizontal property carousel.
- Searchable, district-grouped locations index.
- Data-driven location detail route with destination facts and matching stays.
- Property catalogue with category and budget filters and responsive two-column cards.
- Exact approved destination and property photography bundled locally for native reliability.
- Dynamic route foundations for `/locations/[slug]` and `/properties/[id]`; full property detail remains Phase 5.

## Verification

- `npm run typecheck`
- `npm run lint`
- Impeccable detector
- Browser QA at 390 × 844 and 768 × 1024 across home, locations, location detail, and properties.

Screenshots are stored in `reference/customer-discovery/`.
