Open your backend entry file (`index.js`, `server.js`, `app.js`):

## ✅ STEP 5: FIX CALLBACK URL (CRITICAL)

Your `.env` **MUST MATCH THE BACKEND PORT**

### Example:

If server runs on `5000`:

```env
PAYTM_CALLBACK_URL=http://localhost:5000/payment/paytm/callback
```

If server runs on `3000`:

```env
PAYTM_CALLBACK_URL=http://localhost:3000/payment/paytm/callback
```

Mismatch = guaranteed failure.
