which domain is public

which is owner

which is admin

Hence:

❌ All domains load the public website





NGINX FIXES :  


✅ CORRECT SOLUTION (Proper Architecture)

You MUST have 3 separate server blocks, each with its own root.

Recommended folder structure
/var/www/pawnahavencamp/
├── public-dist/    → Public site build
├── owner-dist/     → Owner dashboard build
├── admin-dist/     → Admin dashboard build

Each domain → its own build folder.

    server_name pawnahavencamp.com www.pawnahavencamp.com;

# 🟢 STEP 1 — Separate Entry Points

You must ensure:

### Public routes

Example:

```
/ → Public site
```

### Owner routes

```
/owner/*
```

### Admin routes

```
/admin/*
```

Your router must already separate these.

If not, you must restructure routes like:

```tsx
<Route path="/" element={<PublicLayout />} />
<Route path="/owner/*" element={<OwnerLayout />} />
<Route path="/admin/*" element={<AdminLayout />} />
```

---

# 🟢 STEP 2 — Modify `vite.config.ts`

You need to enable **multi-page build**.

In `vite.config.ts`, change build config like this:

```ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import { resolve } from 'path'

export default defineConfig({
  plugins: [react()],
  build: {
    rollupOptions: {
      input: {
        public: resolve(__dirname, 'public.html'),
        owner: resolve(__dirname, 'owner.html'),
        admin: resolve(__dirname, 'admin.html'),
      },
    },
    outDir: 'dist',
  },
})
```
